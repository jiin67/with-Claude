# 마지막 접속 LAST LOGIN

실종된 연구원의 **노트북 화면 안에서 펼쳐지는 방탈출 게임**입니다. 웹게임 포털 출시를 목표로 만들었습니다.
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 한국어와 영어를 지원합니다.

## 게임 구성
| 챕터 | 내용 | 퍼즐 |
| --- | --- | --- |
| 1 잠금 화면 | 위젯의 생일로 PIN 알아내기 | PIN |
| 2 금고 | 메모·메일·음악·휴지통을 뒤져 자물쇠 셋 풀기 | 단어(재생 목록 첫 글자), 숫자(영수증 − 팁), 색(일지의 차) |
| 3 ECHO 드라이브 | 터미널에서 드라이브 연결, 암호문 해독, 음성 메모 모스 부호 | 열쇠(연도), 시저 암호, 모스 |
| 4 메시지 | 실종자가 묻는 두 질문에 답하기 | 누가 / 어디서 |

정답과 퍼즐 사슬은 `js/content.js` 맨 위에 정리되어 있습니다.
힌트는 퍼즐마다 3단계이며 첫 단계는 무료, 그다음은 포털 빌드에서 보상형 광고입니다.

## 광고 (포털 빌드에서만)
| 위치 | 종류 |
| --- | --- |
| 힌트 2·3단계 | 보상형 |
| 챕터 2, 3 완료 카드 다음 | 판 사이 광고 |

`?portal=debug`로 열면 가짜 광고로 흐름을 확인할 수 있습니다. `?lang=en`, `?lang=ko`로 언어를 고정할 수 있습니다.

## 업로드 파일 만들기
```bash
node games/last-login/build.mjs            # 전부
node games/last-login/build.mjs crazygames # 하나만
```
결과물은 `games/last-login/dist/lastlogin-<대상>.zip`입니다(약 380KB, 폰트 내장). 대상은 `crazygames`, `poki`, `itch`, `web`입니다.

## 코드 구조
| 파일 | 내용 |
| --- | --- |
| `js/content.js` | 이야기, 앱 내용, 정답, 힌트 (한국어·영어) |
| `js/i18n.js` | 언어 감지, 인터페이스 문구 |
| `js/game.js` | 진행 상태, 정답 판정, 저장. DOM 없음 |
| `js/apps.js` | 노트북 앱 8개의 화면 |
| `js/ui.js` | 타이틀, 잠금 화면, 창과 독, 챕터 카드, 힌트, 설정, 엔딩, 효과음 |
| `js/portal.js` | CrazyGames·Poki 광고 SDK 연결 |
| `build.mjs` | 포털별 zip 빌드 |
| `store/` | 커버, 아이콘, 스크린샷, 등록 문구 |

## 새 퍼즐이나 챕터를 넣으려면
1. `content.js`의 `ANSWERS`와 두 언어의 텍스트에 추가
2. `game.js`에 판정 함수와 `currentHintKey` 분기 추가
3. `apps.js`에서 해당 앱의 화면에 입력을 연결
