# 궤도 제련소 ORBIT FORGE

소행성을 캐서 채굴 함대를 키우는 **방치형 우주 채굴 게임**입니다. 웹게임 포털(CrazyGames 등) 출시를 목표로 만들었습니다.
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 한국어와 영어를 지원합니다.

## 게임 구성
- **채굴**: 소행성을 누르면 광석. 스페이스 바도 됩니다.
- **시설 10종**: 채굴 드론, 레이저 드릴, 광석 자석, 정제소, 화물선, 플라즈마 용광로, 양자 추출기, 중력 흡입기, 항성 수확기, 다이슨 군집. 지은 시설은 궤도에 올라가 화면에 보입니다.
- **개량**: 시설별 9단계(보유 수에 따라 열림), 탭 강화 7종, 함대 전체 강화 7종
- **혜성**: 70~140초마다 지나갑니다. 누르면 광석 보너스 또는 20초 동안 생산 5배
- **항성 붕괴(환생)**: 이번 회차에 광석 1,000만을 캐면 열립니다. 모든 것을 초기화하는 대신 암흑 물질을 얻고, 암흑 물질은 영구 생산 보너스가 됩니다. 유물 6종에 쓸 수도 있습니다.
- **업적 20개**: 하나마다 생산 +2%
- **자리 비움 수익**: 기본 4시간까지, 평소 생산의 50%

## 광고 (포털 빌드에서만)
| 위치 | 종류 | 보상 |
| --- | --- | --- |
| 상단 "광고 보고 2배" | 보상형 | 10분 동안 생산 2배, 최대 60분까지 쌓임 |
| 돌아왔을 때 "광고 보고 2배로 받기" | 보상형 | 자리 비움 수익 2배 |
| 항성 붕괴 직후 | 판 사이 광고 | 없음 (자연스러운 쉬는 지점) |

`?portal=debug`로 열면 가짜 광고로 흐름을 확인할 수 있습니다. `?lang=en`, `?lang=ko`로 언어를 고정할 수 있습니다.

## 업로드 파일 만들기
```bash
node games/orbit-forge/build.mjs            # 전부
node games/orbit-forge/build.mjs crazygames # 하나만
```
결과물은 `games/orbit-forge/dist/orbitforge-<대상>.zip`입니다(약 90KB). 대상은 `crazygames`, `poki`, `itch`, `web`입니다.

## 밸런스 시뮬레이터
```bash
node games/orbit-forge/tools/sim.mjs 3 150 30 70 110
# 초당 3번 탭, 150분 동안, 30·70·110분에 붕괴
```
현재 기준(초당 3번 탭, 가장 이득인 것부터 사는 플레이어):
첫 붕괴 가능 약 20분, 양자 추출기 약 55분, 다이슨 군집 약 2시간 20분.

## 코드 구조
| 파일 | 내용 |
| --- | --- |
| `js/data.js` | 모든 수치: 시설, 개량, 유물, 혜성, 업적 |
| `js/logic.js` | 경제 규칙. DOM이 없어서 시뮬레이터가 그대로 씁니다 |
| `js/i18n.js` | 언어, 문구, 이름, 숫자 표기(만·억·조 / K·M·B) |
| `js/portal.js` | CrazyGames·Poki 광고 SDK 연결 (별표류와 같은 구조) |
| `js/audio.js` | 합성 효과음 |
| `js/render.js` | 캔버스: 소행성, 궤도, 입자, 혜성 |
| `js/ui.js` | 저장, 상점 패널, 튜토리얼, 광고, 입력, 메인 루프 |
| `build.mjs` | 포털별 zip 빌드 |
| `store/` | 커버, 스크린샷, 등록 문구 |
