# 알리바이 ALIBI

탐정의 휴대폰에서 **단체 채팅과 증거를 대조해 거짓말을 찾아내는 추리 게임**입니다. 웹게임 포털 출시를 목표로 만들었습니다.
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 한국어와 영어를 지원합니다.

## 그 밖의 기능
- **오늘의 사건**: 날짜로 정해지는 사건 하나. 시간이 기록되고 연속 일수가 쌓입니다. 잠금과 상관없이 플레이 가능
- **타이머와 최고 기록**: 사건마다 가장 빠른 시간 저장
- **용의자 탭**: 각 사람의 주장을 한눈에, 찾은 거짓말은 초록색
- **기록 복사**: 결과 화면에서 공유 문구 복사
- **바로 플레이**: 처음 접속하면 클릭 없이 1번 사건이 열리고, 다시 오면 사건 목록으로 갑니다. 사건 소개는 채팅 맨 위에 고정
- **가로 화면**: 가로형 창(760px 이상)에서는 휴대폰 프레임 대신 채팅(왼쪽)과 증거·용의자(오른쪽)를 나란히 보여 줍니다
- **용의자 얼굴**: 사건과 사람으로 정해지는 벡터 얼굴(머리 모양·피부·안경·수염 조합). 같은 사람은 같은 얼굴
- **지목 연출**: 범인을 지목하면 채팅에서 탐정의 한마디 → 범인의 반박 → 결정적 증거 → 자백(동기) → 마무리가 순서대로 이어집니다. 대사는 `js/outro-1.js`, `outro-2.js`
- **사건 순서**: `js/i18n.js`의 `ORDER`. 튜토리얼 다음에 반전이 큰 사건(길드 금고, 1204호, 유출된 에피소드)을 앞에 둡니다
- **첫 사건 안내**: 처음 하는 사람에게 증거 탭 → 거짓말 표시 → 범인 지목을 단계별로 가리켜 줍니다
- **배경 음악**: Web Audio로 합성한 잔잔한 패드와 간헐적 음. 설정에서 끌 수 있음

## 규칙
1. 채팅에서 수상한 말을 누르고, **어느 증거와 어긋나는지**를 고릅니다. 말과 증거가 둘 다 맞아야 거짓말로 인정됩니다.
2. 거짓말이 아닌 말을 고르면 실수 1회. 거짓말은 맞았는데 증거가 틀리면, 그 거짓말에 대한 첫 번째 오증거는 실수가 아니고(틀린 증거는 제외 표시되어 다시 고를 수 없음), 두 번째 오증거부터 실수 1회. 실수가 2회 쌓이면 광고를 보고 실수 1회를 되돌릴 수 있다(사건당 1회, 광고가 없는 빌드에서는 이 버튼이 보이지 않음). 실수 3회면 수사 실패가 되지만 찾은 거짓말과 경과 시간은 유지되고, **이어서 수사하기**로 계속할 수 있다. 무료로 이어하면 실수 1회부터, 광고를 보면 실수 0회부터 시작한다. **처음부터 다시**도 선택할 수 있다.
3. 거짓말을 모두 찾으면 **범인 지목**이 열립니다. 틀린 사람을 지목해도 실수 1회.
4. 별 점수: 실수와 힌트가 없으면 ★3, 실수·힌트 각 1회 이하면 ★2, 그 외 ★1. 무료 오증거 1회는 별점에 영향이 없다. 수사 실패를 한 번이라도 한 사건은 최고 ★2.
5. 힌트는 같은 사건 안에서 쓸 때마다 1→2→3단계로 올라간다. 1단계는 아직 못 찾은 거짓말의 화자 이름, 2단계는 그 메시지의 발화자와 시간(전문은 보여주지 않음), 3단계는 어긋나는 증거 1개. 힌트 1회당 광고 1회(광고가 없는 빌드에서는 무료). 힌트 횟수는 별점 계산에 그대로 반영된다.

## 광고 (포털 빌드에서만)
| 위치 | 종류 | 비고 |
| --- | --- | --- |
| 힌트 (1~3단계) | 보상형 | 광고 1회당 다음 단계 1개. 1단계 화자, 2단계 메시지 시간, 3단계 어긋나는 증거 1개 |
| 실수 1회 복구 (실수 2회일 때만) | 보상형 / 힌트 1회 | 사건당 1회. 광고 빌드에서는 광고 1회, 광고 없는 빌드에서는 힌트 1회 사용 (★3 불가) |
| 실패 후 이어하기 (실수 없이) | 보상형 | 무료 이어하기는 실수 1회부터, 광고를 보면 실수 0회부터 |
| 사건 해결 후 결과 화면 진입 | 판 사이 광고 | 사건당 최대 1회. 오늘의 사건 완료도 이 슬롯 하나로 처리 (중복 없음) |
| 실패 후 이어하기 / 처음부터 다시 | 판 사이 광고 | 무료 이어하기·처음부터 선택 시 1회. 광고 이어하기와 중복되지 않음 |

판 사이 광고는 **세션당 최대 6회, 같은 광고 후 최소 90초 간격**(`js/portal.js`의 `MIDGAME_MAX_PER_SESSION`, `MIDGAME_MIN_INTERVAL_MS`). 상한을 넘거나 쿨다운 안이면 조용히 건너뛰고 게임은 계속된다. SDK 로드 실패·광고 차단 시에도 광고 없는 빌드처럼 동작한다. 광고가 없는 빌드(web·itch, `?portal=none`)에서는 힌트와 무료 이어하기가 그대로 동작하고, 실수 없이 이어하기 버튼만 보이지 않는다. 실수 복구 버튼은 모든 빌드에서 보이며, 광고 빌드에서는 광고를 보고, 광고 없는 빌드에서는 힌트 1회를 써서 실수 1회를 되돌린다 (대가로 별점 ★3을 받을 수 없다).

`?portal=debug`로 가짜 광고 확인, `?lang=en`·`?lang=ko`로 언어 고정.

## 업로드 파일 만들기
```bash
node games/alibi/build.mjs            # 전부
node games/alibi/build.mjs crazygames # 하나만
```
결과물은 `games/alibi/dist/alibi-<대상>.zip`(약 360KB, 폰트 내장). 대상은 `crazygames`, `poki`, `itch`, `web`.

## 사건 추가하기
새 파일 `js/cases-h.js`에 `CASES.en.push(...)`, `CASES.ko.push(...)`로 같은 `id`를 추가하고 `index.html`에 스크립트 태그를 넣으면 끝입니다. 추가한 뒤 `node games/alibi/tools/lint-cases.mjs`를 돌리세요. 자백 대사는 `outro-*.js`에 같은 id로 4~6줄 넣고, `ORDER`에 id를 끼워 넣으면 순서가 정해집니다. 규칙 두 가지만 지키면 됩니다.
- 모든 `lie`는 `ev`(어긋나는 `facts`의 0부터 세는 번호, 둘 이상이면 배열)를 가져야 하고, 그 사실과 분명히 어긋나야 합니다.
- `culprit`은 증거만으로 한 명으로 좁혀져야 합니다. 거짓말을 한 사람이 둘 이상이면 좋습니다.
