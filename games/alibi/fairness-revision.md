## 4. 남은 리스크

1. **증거 시트의 "시도함" 제외 표시는 브라우저에서 직접 확인하지 않았다.** Node VM 검증은
   `game.js` 판정 로직까지만 커버한다. `ui.js`의 비활성화 표시는 코드 검토 + `node --check`만
   마친 상태라, 실제 플레이에서 시트가 바로 다시 열리는 흐름을 한 번 눌러봐야 한다.
2. **무료 오증거가 "찍기"를 완전히 막지는 않는다.** 한 거짓말당 무료 1회 + 제외 표시라
   증거를 하나씩 소거해 나갈 수는 있다. 다만 두 번째부터 실수가 쌓여 3회면 실패하므로,
   종전의 "한 번 틀리면 실수"보다는 관대하고, 완전 소거 플레이는 실패 위험을 안는다.
3. **이어하기 후 타이머가 길어지면 최고 기록(`best`)이 불리해진다.** 총 수사 시간을 재므로,
   이어하기로 해결한 기록은 처음부터 다시 푼 기록보다 느리게 남는다. 의도된 선택이지만,
   최고 기록을 노리는 플레이어에게는 "처음부터 다시"가 유리하다는 점을 결과 화면에서
   따로 안내하지는 않는다.
4. **실패 후 이어하기에도 기존 판 사이 광고(`PORTAL.midgame()`)가 그대로 붙는다.**
   광고를 새로 추가한 것은 아니고, 기존 "실패 뒤 다시 수사" 슬롯을 이어하기/처음부터
   둘 다에 그대로 둔 것이다.
