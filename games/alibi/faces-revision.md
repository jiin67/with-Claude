# 등장인물 벡터 얼굴 다듬기 (faces revision)

- 날짜: 2026-11-07
- 대상: `js/ui.js`의 `faceSVG` + 23개 사건 용의자 데이터(`js/cases*.js`)

## 배경

- 얼굴은 사건+인물 id를 시드로 머리·피부·안경·수염 등을 무작위로 뽑는 64×64 벡터(`faceSVG`)였다.
- 성별 정보가 없어 누구에게나 콧수염이 붙을 수 있었고, 실제로 1번 미아가 안경+콧수염+갈색 머리로 나와 남성으로 보인다는 플레이테스트 지적이 있었다. 2번 노아를 해설이 "그녀"라 부른 오류도 같은 뿌리였다.
- 얼굴은 채팅 아바타·용의자 탭·사건 사진(`scenes.js` 경유)·자백 연출·결과 화면에서 동일 시드로 그려지며, "같은 사람은 같은 얼굴" 규칙이 있다.

## 1. 성별 힌트 도입

- 용의자 데이터 `suspects: [[id, 이름, 역할], ...]`에 4번째 요소로 성별 힌트 `'f' / 'm' / 'n'`(중성·불명)을 추가했다. 79명 전원(23개 사건 × 3~4명, 한·영 동일)에 부여했고, EN/KO가 같은 인물에 같은 힌트를 갖는지 Node로 대조 확인했다.
- 부여 기준: ① 대화·해설·자백의 대명사(he/she, 그녀 등)나 역할(손자, 신랑 들러리, Best man 등)이 직접 가리키는 경우, ② 이름이 해당 언어권에서 관습적으로 한 성별로 쓰이는 경우(Ava, Tom, Hugo, 보라, 도현 등). 둘 다 없으면 `'n'`으로 두어 추측으로 단정하지 않았다.
- 부여 현황: **'f' 23명 / 'm' 33명 / 'n' 23명** (언어별 동일).
- `'n'`으로 둔 23명: vase 라파, draft 데브, festival 재, hotel 이 주임·팻, guild 닉스·픽스·퀼, rooftop 모 소장·윤, podcast 렌·새·비, train 델, pool 린, dog 렌, gallery 카이, drone 렌·제이, server 베일·핍, bike 린·파이퍼.
- 이름만으로 판단한 경우(대명사·역할 근거 없음): cake 준(m, 준), exam 시우(m, 시우), karaoke 유리(f, 유리), server 온아(f, Ona), gallery 카이 제외 — 카이는 남녀 모두 쓰여 'n'. 한국 이름 준·시우는 남성으로 쓰이는 경우가 압도적이나, 확정이 아니라 이름 기반 판단임을 밝혀둔다.
- 기존 3요소 구조를 쓰는 코드는 깨지지 않는다. `for (const [id, name, role] of c.suspects)` 같은 분해는 4번째 요소를 무시하고, `nameOf`·역할 표시(`s[2]`)도 그대로 동작한다. `tools/lint-cases.mjs`에 성별 힌트 유효성 검사(`'f'/'m'/'n'` 중 하나)를 추가했다.

## 2. faceSVG 개선 (`js/ui.js`)

- 시그니처: `faceSVG(id)` → `faceSVG(id, g)`. `g`가 없거나 `'f'/'m'`이 아니면 `'n'`으로 처리한다.
- 성별 전달 경로 — 전수 확인 완료:
  - 채팅 아바타·용의자 탭·지목 시트·자백 연출: `face()` 헬퍼가 `R.c`에서 `genderOf(R.c, id)`를 찾아 전달.
  - 사건 사진: `sceneSVG` 안쪽 `face()`가 `genderOf(c, id)`를 전달 (`js/scenes.js`는 건드리지 않았고, 사진 속 `'member'` 같은 비중의자는 `'n'`으로 그려진다).
  - 결과 화면 범인 얼굴: `showSolved`의 `resFace`가 `genderOf(R.c, R.c.culprit)`를 전달.
  - `genderOf(c, id)`는 `c.suspects`에서 찾아 4번째 요소를 반환하고, 없으면 `'n'`이다.
- 성별별 규칙:
  - `'f'`: 수염·콧수염 절대 없음. 긴 머리(스트레이트/웨이브)·밥·번·포니테일·픽시 중 하나. 귀걸이·볼터치 옵션. 눈썹은 얇고 아치형(1.6px), 입술 색은 `#8e3b2f`. 얼굴형은 둥근형/타원형만.
  - `'m'`: 짧은 머리(크롭/가르마/버즈/곱슬/스파이키/쓸어넘김) 중 하나. 수염 옵션(풀비어드/콧수염/고티/없음). 눈썹은 직선형·두껍게(2.6px). 얼굴형은 사각형 포함 3종.
  - `'n'`: 수염 없음. 중간 길이·밥·크롭·곱슬·가르마 중 하나. 중성적인 눈썹(2px), 주근깨·볼터치·점 옵션.
- 공통 개선: 눈에 하이라이트(흰 반사점) 추가, 귀·목·턱 아래 은은한 음영 추가, 머리카락 모양을 성별별 5~6종으로 늘림, 안경·모자·코트는 기존 유지.
- 결정적 생성 유지: 같은 `사건id:인물id` + 같은 성별 힌트 → 바이트 단위 같은 SVG. 저장된 얼굴 데이터가 없어 기존 저장과 충돌하지 않는다. 단, `faceSVG` 내부 뽑기 배치가 바뀌어 모든 얼굴의 생김새가 이전과 달라졌다(의도된 변경).

## 3. 검증

- `node tools/lint-cases.mjs` → ✓ 23 cases ok (성별 힌트 검사 포함).
- `node --check` 통과: `js/ui.js`, `js/cases*.js` 전원.
- Node 자동 검증 (79명 전수): 결정성(같은 입력 두 번 → 동일 SVG), `'f'/'n'` 얼굴에 수염 경로 없음, 귀걸이는 `'f'`에만, 범인 얼굴이 채팅 아바타와 동일 — 전부 통과. 남성 33명 중 수염 있음 19명, 여성 23명 중 귀걸이 있음 8명·볼터치 있음 2명.
- 헤드리스 Chromium(`/opt/meta-chromium/chrome`, WebGL 도메인 정책 파일 사용) 직접 렌더링:
  - 1~4번 사건 용의자 전원 확대(160px) 확인: 미아는 밥 머리·동그란 안경·귀걸이로 여성으로 보이고 수염 없음. 노아는 짧은 회색 머리·큰 미소로 남성으로 보인다. 여성 전원 수염 없음. 채팅 아바타 = 용의자 탭 = 자백 연출 = 결과 화면 얼굴이 미아 기준 바이트 단위 동일함을 DOM에서 확인했다.
  - 79명 전체 그리드 확인: 깨진 얼굴(눈을 가리는 머리, 입을 덮는 수염 등) 없음. 다만 풀비어드(솔·테오·거스 등)는 턱 전체를 덮어 멀리서 보면 큰 미소처럼 보일 수 있다 — 의도된 수염 모양이나, 미묘한 인상 차이는 있다.
- 스크린샷(내부 확인용, repo 미포함): `hidden_files/faces-all.png`, `faces-full.png`, `faces-zoom.png`, `faces-case0~3.png`, `faces-result-mia.png`, `faces-chat-cake.png`.

## 4. 미확인 / 후속 검토

- 실제 휴대폰 너비에서 얼굴 크기·가독성은 확인하지 않았다(헤드리스는 데스크톱 넓은 화면 기준).
- `'n'` 인물 23명은 중성 얼굴이라 성별이 드러나지 않는다. 특정 인물의 성별을 확정할 수 있게 되면 힌트만 바꾸면 얼굴이 따라간다.
- 풀비어드가 미소처럼 보이는 인상은 취향 문제라 두었고, 거슬리면 수염 모양을 다듬는 후속 작업을 할 수 있다.
- 변경 파일: `js/ui.js`, `js/cases.js`, `js/cases-a.js` ~ `js/cases-j.js`, `tools/lint-cases.mjs`, `README.md`(얼굴 설명 문구).
