# 크몽 · 숨고 등록 패키지 — 이벤트 미니게임 제작

복사해서 붙여 넣을 수 있게 정리했습니다. 가격은 제안이니 시장을 보고 조정하세요.

## 서비스 제목 (크몽 기준 30자 안쪽)
- `QR 하나로 끝나는 매장 이벤트 게임 제작 (룰렛·복권·뽑기)`
- 대안: `카페·학원 이벤트용 모바일 룰렛/즉석복권 제작`

## 한 줄 소개
손님이 QR을 찍으면 바로 돌아가는 이벤트 게임을 가게 로고·색·경품에 맞춰 3일 안에 납품합니다. 앱 설치 없음, 서버 비용 없음.

## 서비스 설명

**이런 분께**
- 신메뉴 출시, 오픈 이벤트, 재방문 쿠폰을 재미있게 나눠 주고 싶은 카페·베이커리·식당
- 상담 방문객에게 작은 선물을 주고 싶은 학원·필라테스·미용실
- 행사 부스에서 줄 세우지 않고 경품을 나눠 주고 싶은 분

**제공하는 것**
| 종류 | 설명 |
| --- | --- |
| 행운 룰렛 | 돌리면 경품이 멈추고 쿠폰 코드가 뜹니다 |
| 즉석 복권 | 손가락으로 긁어서 확인. 긁는 소리와 축하 효과 |
| 랜덤 뽑기 상자 | 상자 하나를 고르면 뚜껑이 열리며 경품이 나옵니다 |

**모든 종류 공통**
- 가게 이름·로고·색상 적용
- 경품 최대 8개, 경품별 확률 설정
- 하루 1회 참여 제한(기기 기준), 쿠폰 코드 자동 발급(예: ORU-1105-K7Q2)
- 모바일·PC 대응, 앱 설치 불필요, 서버 불필요
- QR 코드 이미지 제공
- 납품 뒤 경품·확률 변경 1회 무료

**작업 흐름**
1. 주문 후 양식 작성(가게 이름, 로고 파일, 메인 색, 경품 목록과 확률, 하루 참여 횟수)
2. 1~2일 안에 미리보기 링크 전달
3. 수정 1회 반영 후 납품: 파일 묶음 + 호스팅 링크 + QR 이미지

**직원 확인 방법**
손님이 결과 화면을 캡처해서 보여 주면 됩니다. 쿠폰 코드에 날짜가 들어 있어 당일 쿠폰인지 바로 알 수 있어요.

작업 기간: 베이직 2일, 스탠다드 3일, 프리미엄 4일.

## 자주 묻는 질문
- **앱을 설치해야 하나요?** 아니요. 손님은 QR을 찍어 브라우저로 열기만 합니다.
- **같은 손님이 여러 번 할 수 있나요?** 기기 기준으로 하루 참여 횟수를 제한합니다. 완벽한 차단은 아니라서, 직원 확인 시 쿠폰 코드의 날짜를 보시면 됩니다.
- **당첨 확률을 바꿀 수 있나요?** 네. 경품마다 비중을 숫자로 정하고, 납품 뒤에도 설정 파일에서 바꿀 수 있어요. 바꾸는 법은 설명서에 있습니다.
- **호스팅은 어디에?** 무료 정적 호스팅(GitHub Pages, Netlify)에 올려 드리고, 가게 도메인에 연결도 가능합니다.
- **기간이 지나면?** 파일은 영구 소유입니다. 설정만 바꿔 다음 이벤트에 다시 쓰세요.

## 주문 양식 (고객에게 보내는 메시지)
```
1. 가게 이름:
2. 로고 파일(PNG, 없으면 글자 로고로 제작):
3. 메인 색(예: #ff6a3d 또는 "주황"):
4. 게임 종류(룰렛 / 즉석 복권 / 뽑기 상자):
5. 경품 목록과 비중(예: 아메리카노 1잔 5, 10% 할인 20, 다음 기회에 75):
6. 하루 참여 횟수(기본 1회):
7. 결과 화면 안내 문구(예: 쿠폰은 당일에만 유효합니다):
8. 이벤트 기간:
```
