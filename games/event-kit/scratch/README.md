# 즉석 복권 (스크래치 이벤트)

손님이 휴대폰으로 은박을 긁어 상품을 확인하는 **웹 이벤트 페이지**입니다. 설치나 서버 없이 파일 그대로 올리면 동작합니다.
카페·빵집·미용실·학원처럼 매장 이벤트를 하는 곳에 맞춰 로고·색·상품만 바꾸어 납품합니다.

## 동작
1. 손님이 QR을 찍어 페이지를 엽니다.
2. 은박을 손가락으로 긁습니다. 설정한 비율(`revealPercent`)만큼 긁히면 나머지가 자동으로 걷힙니다.
3. 당첨이면 **쿠폰 코드**(예: `MORI-1105-K7Q2`)와 참여 시각이 나오고, 손님은 화면을 캡처해 직원에게 보여 줍니다.
4. 한 기기에서 하루에 `limitPerDay`번만 참여할 수 있습니다. 당첨 결과는 긁기 전에 정해져 저장되므로 새로고침해도 바뀌지 않습니다.

## 고치는 파일: `config.js` 하나
| 항목 | 뜻 |
| --- | --- |
| `brand` | 가게 이름 (상단 작은 글씨, 브라우저 탭) |
| `logoText` / `logoUrl` | 글자 로고 또는 이미지 로고 주소. `logoUrl`이 있으면 이미지를 씁니다 |
| `colors.primary` | 포인트 색 (로고, 카드, 당첨 문구) |
| `colors.bg` / `colors.ink` | 배경색 / 글자색 |
| `colors.foil` | 긁기 전 은박 색 |
| `title` / `subtitle` | 제목과 부제 |
| `prizes` | 상품 목록. `weight`는 상대 확률 (5 : 15 : 80이면 5%, 15%, 80%). `lose: true`는 꽝 |
| `limitPerDay` | 기기당 하루 참여 횟수 |
| `couponPrefix` | 쿠폰 코드 앞머리 |
| `revealPercent` | 몇 % 긁으면 자동으로 전부 걷히는지 |
| `footer` | 맨 아래 안내 문구 (줄바꿈은 `\n`) |
| `text` | 화면의 모든 문구 |

## 올리는 방법 (무료)
- **GitHub Pages**: 저장소에 폴더를 올리고 Settings → Pages에서 공개. 주소는 `https://계정.github.io/저장소/scratch/`
- **Netlify Drop**: app.netlify.com/drop 에 폴더를 끌어다 놓으면 바로 주소가 나옵니다
- 그 밖의 정적 호스팅(Cloudflare Pages, Vercel 등) 모두 가능. `index.html`, `style.css`, `app.js`, `config.js` 네 파일만 있으면 됩니다

## QR 코드
주소가 나오면 무료 QR 생성기(예: qr.io, 네이버 QR코드)에 넣어 인쇄합니다. 테이블 스티커·계산대 안내판·영수증에 붙이면 됩니다.

## 테스트와 초기화
- `?preview=1`: 하루 1회 제한을 무시하고 계속 긁어 볼 수 있습니다. 저장도 하지 않습니다
- `?reset=1`: 이 기기의 참여 기록을 지웁니다
- 소리는 오른쪽 위 버튼으로 끌 수 있습니다

## 확인 방법 (직원용)
쿠폰 코드는 `앞머리-월일-4자리`입니다. 날짜가 오늘이 아니거나 코드 모양이 다르면 유효하지 않습니다.
코드를 서버에 기록하지는 않으므로, 중복 사용을 막으려면 직원이 코드를 적어 두거나 스티커로 표시하세요.
