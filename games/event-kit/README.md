# 이벤트 미니게임 키트

소상공인 이벤트용 미니게임 3종. 각 폴더가 독립된 게임이고, **`config.js` 하나만 바꾸면 납품본**이 됩니다.

| 폴더 | 게임 | 샘플 브랜드 |
| --- | --- | --- |
| `roulette/` | 행운 룰렛 | 카페 오루 |
| `scratch/` | 즉석 복권 | 베이커리 모리 |
| `giftbox/` | 랜덤 뽑기 상자 | 영어학원 브릿지 |

판매 문구·가격·주문 양식은 `SALES.md`에 있습니다.

## 주문이 왔을 때 (10분 납품 절차)
1. 해당 폴더를 복사해 고객 이름으로 폴더를 만듭니다. 예: `roulette` → `cafe-oru`
2. `config.js`를 엽니다. 가게 이름, 로고(이미지 파일을 같은 폴더에 넣고 `logoUrl: 'logo.png'`), 색, 경품과 비중, 하루 참여 횟수, 안내 문구를 바꿉니다.
3. `index.html`을 휴대폰이나 브라우저로 열어 한 번 돌려 봅니다. `?preview=1`을 붙이면 참여 제한 없이 볼 수 있고, `?reset=1`로 기록을 지웁니다.
4. 폴더를 zip으로 묶어 전달하거나, 정적 호스팅에 올리고 링크를 QR로 만듭니다.
   - GitHub Pages: 저장소에 폴더를 넣고 Settings → Pages
   - Netlify Drop: 폴더를 브라우저로 끌어다 놓으면 즉시 주소가 나옵니다
   - QR: 주소를 QR 생성기(무료 사이트 많음)에 넣어 PNG로 저장
5. `README.md`(각 폴더 안)를 설명서로 함께 보냅니다.

## 공통 동작
- 쿠폰 코드: `접두어-MMDD-영숫자4` (예: `ORU-1105-K7Q2`). 날짜가 들어 있어 직원이 당일 쿠폰인지 바로 압니다.
- 하루 참여 제한은 기기의 브라우저 저장소 기준이라 완벽한 차단은 아닙니다. 고객에게 미리 알려 주세요.
- 당첨 내역을 모으려면 `shared/README.md`대로 구글 시트를 연결하세요(5분, 무료). `config.js`의 `sheetUrl`만 채우면 됩니다.
- 외부 의존성 없음. 파일을 그대로 열어도 동작합니다.
