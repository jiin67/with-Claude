# 사다리 타기

매장·행사용 **사다리 타기 미니게임**입니다. 손님이 위쪽 번호 하나를 누르면 표시가 사다리를 타고 내려가 아래 경품에 닿고, 캡처해서 보여 줄 수 있는 **쿠폰 번호**가 생깁니다.
설치나 서버 없이 파일 다섯 개로 동작합니다. `index.html`을 열면 바로 확인할 수 있어요.

## 고객이 바꾸는 것: `config.js` 하나
| 항목 | 뜻 |
| --- | --- |
| `brand` | 화면 위 브랜드 이름 |
| `logoText`, `logoUrl` | 글자 로고 / 로고 이미지 주소. `logoUrl`을 넣으면 이미지가 우선 |
| `colors.primary` | 브랜드 색. 출발 버튼·경로·쿠폰 번호·강조색이 모두 바뀜 |
| `colors.bg`, `colors.ink` | 배경색, 글자색 |
| `title`, `subtitle`, `footer` | 제목, 부제, 맨 아래 안내 문구 |
| `lanes` | 세로 줄 개수 = 출발점 개수 (4~8 권장) |
| `prizes` | 경품 목록. `weight`는 상대 비율(1:3:6:8이면 약 6%·17%·33%·44%). `lose: true`는 꽝 |
| `limitPerDay` | 한 기기에서 하루 참여 횟수. `0`이면 무제한 |
| `couponPrefix` | 쿠폰 번호 앞글자. 번호 형식은 `MOMO-1105-K7Q2` (앞글자-월일-무작위 4자리) |
| `sheetUrl` | 당첨 내역을 구글 시트로 모을 때의 주소(선택 옵션). 비우면 아무것도 보내지 않음 |
| `text` | 화면의 모든 문구 |

## 꼭 알아 둘 점
- **어느 출발점을 고르든 확률은 같습니다.** 아래 경품 칸은 게임을 열 때 `prizes`의 `weight`대로 먼저 정해지고, 사다리는 그 뒤에 무작위로 그려집니다. 사다리 모양은 재미를 위한 연출이고, 결과는 비중대로 나옵니다.
- 경품 칸은 줄마다 따로 뽑히므로, 같은 경품이 여러 칸에 나오거나 어떤 경품이 그날 판에 없을 수도 있습니다. 그래도 각 손님의 당첨 확률은 `weight` 비율 그대로예요.
- 한 번 열린 판(경품 배치와 사다리)은 기기에 저장되어, 새로고침해도 다시 뽑히지 않습니다.
- 참여 제한은 **기기별**(브라우저 저장소)입니다. 다른 폰이나 시크릿 창에서는 다시 참여할 수 있어요. 엄격한 1인 1회가 필요하면 쿠폰 번호를 매장에서 대조하세요(번호에 날짜가 들어 있어 당일 확인이 쉽습니다).
- 쿠폰 번호는 기기에서 만들어지며 기본적으로 서버에 저장되지 않습니다. 직원이 화면을 보고 확인하는 방식입니다. 내역 수집이 필요하면 `sheetUrl` 옵션을 쓰세요(`../shared/README.md` 참고).

## 올리는 방법
파일 다섯 개를 그대로 올리면 됩니다. (`sheetUrl`을 쓰려면 `shared/report.js`도 같은 상위 폴더 구조로 함께 올립니다.)
- **Netlify Drop**: app.netlify.com/drop 에 폴더를 끌어다 놓기 → 바로 주소가 나옵니다 (무료)
- **GitHub Pages**: 저장소에 올리고 Settings → Pages에서 공개
- 그 밖의 어떤 정적 호스팅(카페24, 가비아 웹호스팅 등)도 가능합니다

주소가 생기면 **QR 코드**로 만들어 매장 포스터, 영수증, 테이블에 붙이세요. 무료 QR 생성기 아무거나 쓰면 됩니다.

## 테스트할 때
- 주소 뒤에 `?reset=1` : 이 기기의 참여 기록과 오늘 판을 지움
- 주소 뒤에 `?preview=1` : 참여 제한 없이 계속 해 보기 (고객 시연용)
