# 랜덤 뽑기 상자

매장·학원·온라인 이벤트용 **뽑기 미니게임**입니다. 손님이 상자 하나를 누르면 정해 둔 확률로 경품이 나오고, 캡처해서 보여 줄 수 있는 **쿠폰 번호**가 생깁니다.
설치나 서버 없이 파일 다섯 개로 동작합니다. `index.html`을 열면 바로 확인할 수 있어요.

## 고객이 바꾸는 것: `config.js` 하나
| 항목 | 뜻 |
| --- | --- |
| `brand` | 화면 위 브랜드 이름 |
| `logoText`, `logoUrl` | 글자 로고 / 로고 이미지 주소. `logoUrl`을 넣으면 이미지가 우선 |
| `colors.primary` | 브랜드 색. 상자·쿠폰 번호·강조색이 모두 바뀜 |
| `colors.bg`, `colors.ink` | 배경색, 글자색 |
| `title`, `subtitle`, `footer` | 제목, 부제, 맨 아래 안내 문구 |
| `boxes` | 상자 개수 (3~9 권장) |
| `prizes` | 경품 목록. `weight`는 상대 비율(10:20:40:30이면 10%·20%·40%·30%). `lose: true`는 꽝 |
| `limitPerDay` | 한 기기에서 하루 참여 횟수. `0`이면 무제한 |
| `couponPrefix` | 쿠폰 번호 앞글자. 번호 형식은 `BRG-1105-K7Q2` (앞글자-월일-무작위 4자리) |
| `text` | 화면의 모든 문구 |

## 꼭 알아 둘 점
- **모든 상자의 확률은 같습니다.** 어느 상자를 누르든 `prizes`의 `weight`대로 뽑힙니다. 상자 고르기는 재미를 위한 연출이에요.
- 참여 제한은 **기기별**(브라우저 저장소)입니다. 다른 폰이나 시크릿 창에서는 다시 참여할 수 있어요. 엄격한 1인 1회가 필요하면 쿠폰 번호를 매장에서 대조하세요(번호에 날짜가 들어 있어 당일 확인이 쉽습니다).
- 쿠폰 번호는 기기에서 만들어지며 서버에 저장되지 않습니다. 직원이 화면을 보고 확인하는 방식입니다.

## 올리는 방법
파일 다섯 개를 그대로 올리면 됩니다.
- **Netlify Drop**: app.netlify.com/drop 에 폴더를 끌어다 놓기 → 바로 주소가 나옵니다 (무료)
- **GitHub Pages**: 저장소에 올리고 Settings → Pages에서 공개
- 그 밖의 어떤 정적 호스팅(카페24, 가비아 웹호스팅 등)도 가능합니다

주소가 생기면 **QR 코드**로 만들어 매장 포스터, 영수증, 테이블에 붙이세요. 무료 QR 생성기 아무거나 쓰면 됩니다.

## 테스트할 때
- 주소 뒤에 `?reset=1` : 이 기기의 참여 기록을 지움
- 주소 뒤에 `?preview=1` : 참여 제한 없이 계속 뽑아 보기 (고객 시연용)
