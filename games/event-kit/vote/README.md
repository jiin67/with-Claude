# 투표·설문 이벤트

손님이 QR을 찍으면 질문 1~3개에 답하고, 다 답하면 **참여 쿠폰**을 받는 이벤트 페이지입니다.
신메뉴 투표, 방문 빈도 조사, 한마디 받기 같은 데 쓰세요. 앱 설치도, 서버도 필요 없습니다.

## 바꾸는 법 — `config.js` 하나만 수정
| 항목 | 설명 |
| --- | --- |
| `brand`, `logoText`, `logoUrl` | 가게 이름, 글자 로고, 로고 이미지(같은 폴더에 넣고 `'logo.png'`처럼 적음. 비우면 글자 로고) |
| `colors.primary` | 브랜드 색. 이것 하나만 바꿔도 전체 분위기가 바뀝니다 |
| `title`, `subtitle`, `footer` | 제목, 부제, 맨 아래 안내 문구 |
| `questions` | 질문 목록(최대 3개). 각 질문은 아래 셋 중 하나 |
| └ `{ q, options }` | 하나만 고르는 문항 |
| └ `{ q, options, multi: true }` | 여러 개 고를 수 있는 문항 |
| └ `{ q, free: true }` | 자유 입력(120자). 건너뛸 수 있음 |
| `reward.label` | 참여 보상 이름(결과 화면에 크게 표시) |
| `reward.couponPrefix` | 쿠폰 번호 앞글자. 예: `ORU-1105-K7Q2` (가운데는 날짜) |
| `showResults` | `true`면 결과 화면에 투표 그래프 표시 |
| `seedResults` | 그래프 초깃값. 질문 순서대로, 선택지 순서대로 숫자. 예: `[[14, 9, 11, 6], [5, 12, 9, 4]]`. 자유 입력 문항은 건너뜀(빈 배열 `[]`을 두거나 생략) |
| `limitPerDay` | 한 기기에서 하루 참여 횟수. `0`이면 제한 없음 |
| `sheetUrl` | 구글 시트로 응답을 모을 때 사용(아래 참고) |
| `text` | 화면의 모든 문구 |

## 결과 그래프는 "이 기기" 기준입니다 (꼭 읽어 주세요)
이 페이지는 서버가 없습니다. 결과 그래프는 **`seedResults` 초깃값 + 이 휴대폰에서 한 응답**만 합산해서 보여 줍니다.
손님마다 자기 휴대폰에서 보는 숫자가 조금씩 다릅니다. 분위기용 그래프로는 충분하지만, **실제 집계가 필요하면 구글 시트 옵션을 쓰세요.**

### 구글 시트로 응답 모으기 (옵션)
`../shared/report.js`의 안내대로 구글 앱스 스크립트 주소를 만들어 `config.js`의 `sheetUrl`에 넣으면, 제출할 때마다 쿠폰 번호·시각·응답 내용이 시트에 한 줄씩 쌓입니다.
`sheetUrl`이 비어 있으면 아무것도 보내지 않고, 페이지는 똑같이 동작합니다.

## 손님이 보는 흐름
1. QR을 찍으면 첫 질문이 바로 나옵니다 (설명 화면 없음)
2. 선택지를 누르고 "다음". 자유 입력은 "건너뛰기" 가능
3. 마지막 질문에서 "제출하고 쿠폰 받기" → 쿠폰 번호 + 참여 시각 + "캡처해서 직원에게 보여 주세요"
4. 같은 기기에서 다시 열면 질문 대신 오늘 받은 쿠폰이 보입니다

## 테스트와 초기화
- `index.html?preview=1` — 참여 제한 없이 몇 번이고 해 볼 수 있습니다(쿠폰은 저장되지 않음)
- `index.html?reset=1` — 이 기기의 참여 기록과 그래프 집계를 지웁니다
- 파일을 그대로 열어도(`file://`) 동작합니다

## 올리는 법
- **Netlify Drop**: 폴더를 브라우저 창으로 끌어다 놓으면 바로 주소가 나옵니다
- **GitHub Pages**: 저장소에 폴더를 넣고 Settings → Pages
- 그 밖의 어떤 정적 호스팅이든 됩니다. 주소를 QR 생성기에 넣어 PNG로 저장해 매장에 붙이세요

## 직원 확인 요령
쿠폰 번호 가운데가 날짜(월일)입니다. 오늘 날짜가 아니면 지난 쿠폰입니다. 기기 기준 제한이라 완벽한 중복 차단은 아니니, 번호를 적어 두면 재사용을 막을 수 있습니다.
