# 당첨 내역을 구글 시트로 모으기

손님이 룰렛·복권·뽑기를 할 때마다 결과 한 줄이 사장님의 구글 시트에 쌓입니다. 서버도, 월 비용도 없습니다.
설정은 5분이면 끝나고, 세 가지 게임 모두 같은 방법입니다.

## 설정 (5분)
1. [구글 시트](https://sheets.google.com)에서 새 스프레드시트를 만듭니다. 이름은 아무거나.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 열린 편집기의 기본 코드를 모두 지우고, 이 폴더의 `apps-script.gs` 내용을 통째로 붙여 넣고 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 요청이 뜨면 허용(“안전하지 않음”이라고 나와도 본인이 만든 스크립트이니 **고급 → 이동**)
5. 나온 **웹 앱 URL**을 복사해 게임 폴더의 `config.js` 안 `sheetUrl: ''` 따옴표 사이에 붙여 넣습니다.
6. 브라우저 주소창에 그 URL을 넣어 `ok`가 보이면 끝.

코드를 바꾼 뒤에는 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.

## 시트에 쌓이는 열
| 열 | 뜻 |
| --- | --- |
| 시각 | 손님이 결과를 받은 시각 |
| 브랜드 | `config.js`의 `brand` |
| 경품 | 뽑힌 경품 이름 |
| 쿠폰 코드 | 발급된 코드(꽝이면 비어 있음). 직원이 쿠폰을 받을 때 이 열에서 찾아 **사용 표시**를 해 두면 중복 사용을 막을 수 있습니다 |
| 결과 | 당첨 / 꽝 |
| 시간대 | 손님 기기의 시간대 |
| 페이지 | 어느 게임 폴더에서 왔는지 |
| 브라우저 | 손님 브라우저 정보 |

## 알아 둘 것
- 게임은 결과를 **보내기만** 하고, 시트에 잘 적혔는지는 확인하지 못합니다(브라우저 보안 규칙상 응답을 읽을 수 없음). 설정 뒤 반드시 시트를 열어 한 줄 들어오는지 보세요.
- 인터넷이 잠깐 끊겨 보내지 못한 결과는 손님 기기에 최대 50건 보관했다가 다음에 그 페이지를 열 때 다시 보냅니다.
- 손님의 이름·전화번호 같은 개인정보는 전혀 수집하지 않습니다. 브라우저 종류(사용자 에이전트)만 함께 보냅니다. 이것도 원치 않으면 `apps-script.gs`에서 마지막 열을 빼면 됩니다.
- 시트 한 장에 수십만 줄까지 들어가므로 작은 가게 이벤트에는 충분합니다.

## 테스트하는 법
1. 게임 주소 뒤에 `?reset=1`을 붙여 한 번 열어 참여 기록을 지웁니다.
2. 주소에서 `?reset=1`을 떼고 다시 열어 한 번 플레이합니다.
3. 구글 시트를 열어 보면 몇 초 안에 한 줄이 추가되어 있습니다. 안 보이면 배포의 액세스 권한이 **모든 사용자**인지, `sheetUrl`에 붙여 넣은 주소가 `/exec`로 끝나는지 확인하세요.

## 납품 시 체크
- [ ] `config.js`의 `sheetUrl`에 고객 시트의 웹 앱 URL
- [ ] 시트는 고객 구글 계정으로 만들 것(그래야 고객이 소유)
- [ ] 테스트 플레이 한 번 → 시트에 한 줄 확인 → 테스트 줄은 삭제
