# 행운 룰렛 (이벤트 미니게임)

손님이 휴대폰으로 룰렛을 돌려 상품이나 할인 쿠폰을 받는 이벤트 페이지입니다. 카페, 매장, 학원 이벤트에 쓰도록 만들었고, 설치나 서버 없이 **파일 그대로 올리면** 동작합니다.

- 상품과 확률, 색, 문구를 `config.js` 한 파일로 바꿉니다.
- 한 기기에서 하루 참여 횟수 제한, 당첨 쿠폰 코드(예: `ORU-1105-K7Q2`)와 참여 시각 표시.
- 휴대폰 화면에 맞춰 만들었고 PC에서도 보입니다. 인터넷 없이 `index.html`을 열어도 됩니다.

## 설정 바꾸기 (`config.js`)
| 항목 | 뜻 |
| --- | --- |
| `brand` | 가게 이름 (로고 아래, 브라우저 탭 제목) |
| `logoText` / `logoUrl` | 로고. `logoUrl`에 이미지 주소를 넣으면 그 이미지가, 비우면 `logoText` 글자가 보입니다 |
| `colors.primary` | 버튼·포인터·강조색. `bg` 배경색, `ink` 글자색 |
| `title`, `subtitle` | 제목과 한 줄 설명 |
| `prizes` | 상품 목록 2~8개. `label` 이름, `weight` 상대 확률(전체 합 중 비율), `color` 칸 색(비우면 자동), `miss: true`는 꽝(축하 효과 없음, 쿠폰 코드 없음) |
| `limitPerDay` | 한 기기에서 하루 참여 횟수. `0`이면 제한 없음 |
| `couponPrefix` | 쿠폰 코드 앞머리 |
| `footer` | 맨 아래 안내 문구 |
| `text` | 버튼과 안내 문구 전부. 말투를 바꾸고 싶을 때 |

확률 예: `weight`가 5, 20, 60이면 각각 5/85, 20/85, 60/85 확률입니다. 칸 크기는 모두 같고 확률만 다릅니다.

## 올리기
1. **GitHub Pages**: 저장소에 이 폴더를 올리고 Settings → Pages에서 브랜치를 고르면 `https://아이디.github.io/저장소/roulette/` 주소가 생깁니다.
2. **Netlify Drop**: app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 바로 주소가 나옵니다. 가장 빠릅니다.
3. 그 밖의 정적 호스팅(카페24, Vercel 등) 어디든 `index.html`, `style.css`, `app.js`, `config.js` 네 파일만 올리면 됩니다.

## QR 코드로 만들기
위에서 나온 주소를 QR 생성 사이트(네이버 QR코드, qr.io 등)에 넣어 인쇄하면 됩니다. 매장 테이블이나 계산대에 붙여 두세요.

## 테스트와 초기화
- 하루 1회 제한 때문에 다시 돌려 보고 싶으면 주소 뒤에 `?reset=1`을 붙여 엽니다. 예: `index.html?reset=1`
- 제한을 무시하고 계속 돌려 보려면 `?preview=1`
- 쿠폰 확인: 손님이 당첨 화면(쿠폰 코드와 시각)을 캡처해서 보여 줍니다. 코드의 가운데 네 자리는 날짜(월일)라 당일 것인지 바로 알 수 있습니다.

## 한계
참여 제한은 손님의 기기(브라우저 저장소) 기준이라, 브라우저 데이터를 지우거나 다른 기기를 쓰면 다시 참여할 수 있습니다. 상품 가치가 큰 이벤트라면 쿠폰 코드를 매장에서 기록해 중복을 막으세요.
