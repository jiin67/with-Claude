# 별표류 STARDRIFT

항로를 잃은 정찰기로 **10분을 버티는** 네온 우주 생존 슈팅 게임입니다.
무기는 자동으로 발사되고, 플레이어는 피하고, 경험치 결정을 모으고, 레벨 업마다 강화를 고릅니다.

설치나 빌드 없이 `index.html` 하나로 동작합니다. 파일을 브라우저로 열면 바로 플레이할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD · 방향키 | 이동 |
| 화면 드래그 (터치·마우스) | 이동 (모바일 지원) |
| 1 · 2 · 3 | 강화 선택 |
| R | 강화 다시 뽑기 (판당 2회) |
| Esc · P | 일시정지 |
| M | 소리 켜기/끄기 |

## 게임 구성

- **무기 6종**: 펄스 블래스터(기본), 궤도 칼날, 연쇄 번개, 충격파, 추적 미사일, 반응 보호막
- **강화 16종**: 분산 발사, 관통탄, 연사 가속, 과충전 코어, 치명 조준, 증폭 렌즈, 냉각 순환기, 추진기 개조, 장갑 증설, 나노 수리, 중력 수집기 등
- **적 6종**: 추적하는 드론, 돌진하는 대셔(점선으로 예고), 거리를 두고 쏘는 스피터, 죽으면 쪼개지는 스플리터, 단단한 브루트, 금색 테두리의 정예 개체(보물 상자 드롭)
- **보스**: 3분마다 등장. 방사탄·나선탄·조준 부채꼴·소환·돌진 패턴을 번갈아 씁니다. 처치하지 못하면 다음 차례에 광폭화합니다.
- **이벤트**: 50초마다 사방에서 포위망이 좁혀옵니다.
- 10분 생존 시 클리어. 이후 무한 모드로 계속할 수 있습니다.
- 효과음과 배경음악은 모두 Web Audio로 실시간 합성합니다. 외부 에셋 파일이 없습니다.
- 최고 기록은 브라우저에 저장됩니다.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**로 이동
2. **Source**를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 선택 후 저장
3. 1~2분 뒤 `https://jiin67.github.io/with-Claude/` 에서 플레이

## 개발 메모

- 순수 JavaScript + Canvas 2D, 의존성 없음
- 충돌 판정은 공간 해시 그리드로 처리해 적 수백 마리에서도 60fps 유지
- 브라우저 콘솔의 `window.__stardrift`로 자동 조종(`autopilot(true)`)과 고속 시뮬레이션(`sim(초)`)을 돌릴 수 있어 밸런스 테스트에 씁니다.
