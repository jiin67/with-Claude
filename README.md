# 별표류 STARDRIFT

네온 우주를 배경으로 한 **생존 슈팅 로그라이트**입니다.
무기는 자동으로 발사되고, 플레이어는 피하고, 경험치 결정을 모으고, 레벨 업마다 강화를 고릅니다.
판이 끝나면 별가루를 모아 격납고에서 기체와 영구 강화를 사고, 더 어려운 항로에 도전합니다.

설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
한국어와 영어를 지원합니다. 브라우저 언어를 따라가고, 설정에서 바꿀 수 있습니다.

> 웹게임 포털(CrazyGames, Poki, itch.io)에 올려 수익을 내는 방법은 [MONETIZATION.md](MONETIZATION.md)에 정리했습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD · 방향키 | 이동 |
| 화면 드래그 (터치·마우스) | 이동 (모바일 지원) |
| 1 · 2 · 3 | 강화 선택 |
| R | 강화 다시 뽑기 |
| Esc · P | 일시정지 |
| M | 소리 켜기/끄기 |

## 게임 구성

### 항로 4개
| 항로 | 길이 | 특징 |
| --- | --- | --- |
| 잔해 지대 | 8분 | 입문 스테이지. 하이브 코어 → 최종 보스 쌍둥이 성운 |
| 진홍 성운 | 9분 | 저격수·수호자 등장. 크리스탈 거상 → 폭풍의 눈 → 공허의 여왕 |
| 사건의 지평선 | 10분 | 모든 적. 폭풍의 눈 → 공허의 여왕 → 종말 기관 |
| 무한 공허 | 끝없음 | 2분 30초마다 보스가 강해지며 돌아옴 |

최종 보스를 쓰러뜨리면 클리어하고 다음 항로가 열립니다.

### 기체 5종
정찰기 별똥(균형), 요격기 창살(레일건·고속), 방벽함 바위(탱커), 공명기 메아리(범위), 지휘함 등대(윙맨 드론·성장)

### 무기 12종 (한 판에 최대 6개)
펄스 블래스터, 궤도 칼날, 연쇄 번개, 충격파, 추적 미사일, 반응 보호막, 레일건, 지뢰 살포기, 특이점, 윙맨 드론, 회전 레이저, 회귀 원반

### 무기 진화 6종
무기를 **최대 레벨**까지 올리고 **짝이 되는 강화**를 하나라도 가지고 있으면, 다음에 여는 **보물 상자**(정예 개체·보스가 떨어뜨림)에서 진화 카드가 나옵니다.
레벨 업 카드에는 진화 재료인 무기·강화마다 진화 조건이 표시되고, 한 번 얻은 진화는 기록실 도감에 남습니다.

| 진화 | 무기 (최대 레벨) | 짝 강화 | 효과 |
| --- | --- | --- | --- |
| 은하 고리 | 궤도 칼날 | 증폭 렌즈 | 칼날 7개, 반경·크기 확대, 피해 +35% |
| 뇌신의 심판 | 연쇄 번개 | 치명 조준 | 번개 두 갈래, 각 11마리 연쇄, 피해 +30% |
| 유성우 | 추적 미사일 | 냉각 순환기 | 사방으로 6발, 폭발 범위 +50%, 재사용 -30% |
| 항성 관통포 | 레일건 | 과충전 코어 | 빔 5줄 부채꼴, 피해 +20%, 재사용 -15% |
| 붕괴 항성 | 특이점 | 지속 장치 | 블랙홀 두 곳, 반경 +40%, 피해 +50% |
| 초공간 원반 | 회귀 원반 | 추진기 개조 | 원반 4개를 사방으로, 사거리 +40%, 피해 +25% |

### 적 12종
드론, 대셔, 스피터, 스플리터, 진드기, 브루트, 저격수, 자폭병, 수호자, 위상체, 산란체, 궤도병 + 금색 테두리의 정예 개체

### 보스 6종
| 보스 | 패턴 |
| --- | --- |
| 하이브 코어 | 방사탄, 나선탄, 조준 부채꼴, 소환, 돌진 |
| 쌍둥이 성운 | 체력 절반에서 둘로 분열 |
| 크리스탈 거상 | 틈 있는 고리탄, 떨어지는 파편, 충격 고리 |
| 폭풍의 눈 | 끌어당기기, 예고된 번개, 이중 나선 |
| 공허의 여왕 | 순간이동, 공허 지대, 유도탄 |
| 종말 기관 | 회전 레이저, 탄막 벽, 유도 미사일 |

### 성장
- **별가루**: 처치 수·생존 시간·보스 격파·클리어로 획득
- **격납고**: 영구 강화 9종(공격력, 내구도, 속도, 수집 범위, 경험치, 치명타, 다시 뽑기, 비상 재가동, 별가루 획득량)과 기체 해금
- **업적 24개**: 달성하면 별가루 보상
- **도감**: 만난 적과 보스, 얻은 무기 진화 기록
- 첫 출격에는 튜토리얼이 안내합니다.

저장 데이터는 브라우저에만 보관됩니다.
효과음과 배경음악은 모두 Web Audio로 실시간 합성하며 외부 에셋 파일이 없습니다.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**로 이동
2. **Source**를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 선택 후 저장
3. 1~2분 뒤 `https://jiin67.github.io/with-Claude/` 에서 플레이

충돌 판정은 공간 해시 그리드로 처리해 적 수백 마리에서도 60fps를 유지합니다.

### 밸런스 시뮬레이터
브라우저 콘솔의 `window.__stardrift`로 자동 조종과 고속 시뮬레이션을 돌릴 수 있습니다.

```js
// 진홍 성운을 영구 강화 2단계로 10판 시뮬레이션
__stardrift.batch(1, ['scout', 'lancer', 'bastion', 'resonator', 'warden'], 10, 800, 2)
```

현재 자동 조종 기준 클리어율(무기 진화 포함, 80~120판): 잔해 지대(강화 없음) 약 95%, 진홍 성운(강화 없음) 약 25%, 사건의 지평선(강화 4단계) 약 75%.
결과의 `evo` 항목에 그 판에서 얻은 무기 진화가 표시됩니다.
